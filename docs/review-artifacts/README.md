# Prescription PDF review artifacts

Synthetic, generated by the production renderer (`QuestPdfPrescriptionRenderer`) from fake data
only — no real patient, doctor, or clinic information. Regenerate by running the print unit
tests and the scratch render harness; they are review evidence for the Phase 3 visual
verification, not fixtures consumed by tests.

- `prescription-sample-arabic.pdf` / `...-page1.png`: Arabic (RTL) one-page sample.
- `prescription-sample-english-multipage.pdf` / `...-page1.png`: English sample, 4 pages,
  demonstrating pagination and page numbering.

Visually verified during the Phase 3 review: Arabic shaping and RTL layout, correct
numeric/unit order inside bidirectional text ("500 mg", "1 tablet", "7 days"), visible
translation-fallback disclosure, paginated tables with repeated headers/footers and
"Page X / Y" numbering, and the seven-column item table including instructions.
